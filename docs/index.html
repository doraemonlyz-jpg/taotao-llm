双轨实现的逻辑

为什么不只学工业版

HuggingFace 一行 SFTTrainer(...).train() 能做 SFT · 但你不知道它在做什么。 nano 版用 200 行 PyTorch 写一遍 · 你能讲出 chat template / loss masking / packing · 这是面试里把 mid 跟 senior 拉开的差距。

为什么不只学教学版

nano 跑不了真 7B 模型 · 也不会用 wandb / lm-eval / FSDP。能 ship 的工程师能读懂教学版 + 用工业版交付。两条腿走路。

跟 taotao-agent 的关系

姊妹项目 taotao-agent 是 27 本书的 agent 全栈 reference。两个项目的接合点在 phase 9 · 量化导出 → 注册到 Ollama → agent 跑你训的模型。
